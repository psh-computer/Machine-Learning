# Language Modeling Coursework

These notebooks are course exercises for tokenizer construction and a small GPT-style language model. They are grouped here as learning materials, separate from the standalone portfolio projects.

## Notebooks

- [`day02_01_text_data_tokenizer_v1_1.ipynb`](day02_01_text_data_tokenizer_v1_1.ipynb): trains a mixed-corpus BPE tokenizer and compares tokenization behavior.
- [`day02_lab_minigpt_student_v2_1.ipynb`](day02_lab_minigpt_student_v2_1.ipynb): educational MiniGPT implementation and next-token prediction exercise.

Both notebooks target Google Colab and install dependencies in notebook cells. The MiniGPT notebook is an instructional exercise; review its TODOs and run cells in order in a fresh runtime.
